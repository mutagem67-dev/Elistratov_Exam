# Система оформления заказов "Чудо Обувь"
## Технологии
- Python 3
- Tkinter (GUI)
- PostgreSQL (База данных)
- Pandas (Аналитика)

## Функционал
- Авторизация пользователей по логину
- Просмотр каталога обуви
- Учет скидок и остатков на складе
- Оформление заказов

## Запуск
1. Создать БД в PostgreSQL и выполнить скрипт `db_setup.sql`
2. Установить библиотеки: `pip install psycopg2-binary pandas`
3. Запустить: `python3 main.py`
